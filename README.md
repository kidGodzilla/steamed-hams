# Steamed Hams — Voxel Edition

A first-person 3D voxel luncheon. Superintendent Chalmers is coming over. Make a good impression!

## Play

```bash
npm install
npm run dev
```

## Controls

- **Click** — capture mouse
- **WASD** — move
- **Mouse** — look
- **E** — interact
- **Esc** — release mouse

## How to win

1. Answer the door and seat Chalmers
2. Discover the ruined roast — *delightfully devilish*
3. Climb out the **kitchen window** (calves / steamed clams)
4. Deliver and serve the steamed hams · survive Albany / Utica
5. Check the kitchen → *I'm pooped* → **GOOD LORD!** → Aurora Borealis → **No.**
6. Flee outside — verdict: *you steam a good ham*
